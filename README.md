# ER Companion

**ER Companion**은 이터널 리턴 픽 화면에서 같은 팀 플레이어의 정보를 빠르게 확인할 수 있도록 도와주는 오버레이 프로그램입니다.

별도의 복잡한 설정 없이 프로그램을 실행해두면 픽 화면을 인식하여 필요한 정보를 자동으로 표시합니다.

---

## 주요 기능

픽 화면에서 같은 팀 플레이어의 정보를 오버레이로 확인할 수 있습니다.

표시할 수 있는 정보는 다음과 같습니다.

- 모스트 실험체
- 플레이 판수
- 승률
- 평균 플레이어 피해량
- 평균 킬

게임 모드에 따라 오버레이 사용 여부와 표시 방식을 각각 설정할 수 있습니다.

---

## 자동으로 작동합니다

ER Companion을 실행해둔 상태에서 이터널 리턴을 플레이하면 됩니다.

픽 화면에 들어가면 오버레이가 자동으로 표시되고,  
픽 화면을 벗어나면 자동으로 숨겨집니다.

게임을 할 때마다 별도로 오버레이를 켜고 끌 필요가 없습니다.

---

## 설치 방법

### 1. 설치 파일 다운로드

Releases 페이지에서 최신 버전의

`ERCompanion_Setup.exe`

파일을 다운로드합니다.

### 2. 설치

다운로드한 설치 파일을 실행하고 안내에 따라 설치합니다.

Windows에서 출처를 확인할 수 없다는 경고가 표시되는 경우  
`추가 정보` → `실행`을 선택하면 설치를 계속할 수 있습니다.

### 3. ER Companion 실행

설치가 완료되면 ER Companion을 실행합니다.

이후 원하는 오버레이 설정을 조정한 뒤 평소처럼 이터널 리턴을 실행하면 됩니다.

---

## 오버레이 설정

사용 환경에 맞게 오버레이를 자유롭게 설정할 수 있습니다.

### 게임 모드 설정

원하는 게임 모드에서만 오버레이를 사용할 수 있습니다.

사용하지 않는 모드에서는 오버레이를 끌 수 있습니다.

### 표시 정보

오버레이에 표시할 정보를 원하는 대로 선택할 수 있습니다.

자주 확인하는 정보만 표시하고 필요하지 않은 항목은 숨길 수 있습니다.

### 크기 및 투명도

모니터 크기나 취향에 맞게 오버레이의 크기와 투명도를 조절할 수 있습니다.

### 위치 조정

`위치 조정` 기능을 사용하면 오버레이를 직접 드래그하여 원하는 위치로 이동할 수 있습니다.

위치를 정한 뒤 위치 조정을 종료하면 해당 위치가 저장됩니다.

필요한 경우 기본 위치로 다시 되돌릴 수도 있습니다.

---

## 처음 사용할 때 추천 설정

처음 사용하는 경우 아래 순서대로 설정하면 편합니다.

1. ER Companion 실행
2. 사용할 게임 모드 설정
3. 표시할 정보 선택
4. 크기와 투명도 조절
5. 미리보기 확인
6. 위치 조정
7. 이터널 리턴 실행
8. 픽 화면 진입

한 번 설정해두면 이후에는 ER Companion을 실행한 상태에서 평소처럼 게임을 이용하면 됩니다.

---

## 미리보기

게임을 실행하지 않아도 설정 화면에서 오버레이가 어떻게 표시되는지 미리 확인할 수 있습니다.

표시 정보, 크기, 투명도 또는 위치를 조정할 때 활용하면 편리합니다.

---

## 오버레이가 표시되지 않을 때

다음 내용을 먼저 확인해주세요.

1. ER Companion이 실행되어 있는지 확인
2. 현재 게임 모드에서 오버레이 사용이 켜져 있는지 확인
3. 이터널 리턴 픽 화면에 진입했는지 확인
4. 프로그램을 완전히 종료한 뒤 다시 실행

게임 업데이트나 픽 화면의 UI가 변경된 직후에는 일부 인식 기능이 일시적으로 정상 작동하지 않을 수 있습니다.

---

## 게임 중에는 표시되지 않나요?

네.

ER Companion은 픽 화면에서 팀 정보를 확인하기 위한 프로그램입니다.

픽 화면을 벗어나 실제 게임이 시작되면 오버레이는 자동으로 숨겨집니다.

---

## 프로그램 동작 방식

ER Companion은 게임 프로세스에 코드를 삽입하거나 게임 메모리를 수정하는 방식으로 동작하지 않습니다.

게임 이용에 불필요한 조작 없이 픽 화면에서 필요한 정보를 확인할 수 있도록 제작되었습니다.

---

## 시스템 요구사항

- Windows 10 / 11
- 64비트 Windows
- 인터넷 연결

별도의 .NET Runtime 설치는 필요하지 않습니다.
